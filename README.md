# Netflix Data Analysis

A Python-based exploratory analysis of Netflix movies and TV shows.  
The project focuses on understanding content types, ratings, countries, release years, and movie durations through data cleaning and visualization.

### Tools
Python • Pandas • NumPy • Matplotlib • Seaborn

### What I Worked On
- Cleaned and explored the Netflix dataset
- Compared Movies and TV Shows
- Analyzed ratings, countries, release years, and durations
- Created visualizations to identify trends and patterns

### Project Structure
- `netflix.py` — analysis code
- `netflix_8000_rows_dataset.csv` — dataset
- `visualizations/` — generated charts
